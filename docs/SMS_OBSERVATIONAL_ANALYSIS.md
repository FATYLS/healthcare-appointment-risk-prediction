# SMS observational analysis

In the historical data:

- No SMS: **16.70%** no-show rate.
- SMS received: **27.57%** no-show rate.
- Absolute difference: **10.87 percentage points**.
- Relative difference: approximately **65.1%**.
- Two-proportion z-test: **z = 42.03, p < 0.001**.

## Interpretation

The groups differ statistically, but this is an observational comparison. SMS assignment may depend on appointment timing, patient characteristics or operational targeting. Therefore it is **not valid to conclude that SMS causes more or fewer no-shows** from this dataset alone.

A randomized A/B test is the appropriate design for estimating causal impact.
