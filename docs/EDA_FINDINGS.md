# EDA findings

1. The no-show class represents about **20.2%** of valid appointments, so the task is imbalanced.
2. Waiting time is an important operational variable and is useful for prediction.
3. Age is also informative in the historical data.
4. SMS receipt is associated with the outcome, but the association is not causal evidence.
5. The dataset comes from 2016 and a specific healthcare context; generalization must not be assumed.
